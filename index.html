How to use the 10-Key

The basics

Type an amount, then + = to add it or − to subtract — every press prints on the paper roll. The line under the display is the running TOTAL since the last T. S prints a dashed subtotal; T prints the grand total (double line) and starts a new section. Both print the item count since the last T.

Scroll up a long roll and a small capsule appears at the bottom-left showing the roll’s last printed Total (or the running Σ if no T has been printed yet).

The keys

0–9 · 00 · •Enter amounts ( • is the decimal point)
+ =Add (green key). With nothing typed, repeats the last amount
−Subtract (red key). Empty too — repeats the last amount
× · ÷Multiply / divide: type A, ×, type B, then + or − posts the result · chains (200 × 30 ÷ 5 +) keep one pending value
%Percent of the total (or of a pending ×/÷). Held until + or − posts it
S · TSubtotal · grand total (with item counts)
CStart a new transaction — clears the running total, typed digits, pending ×/÷, held % and note · press twice quickly to empty the whole roll (other rolls are never affected)
⌫ · ±Delete last digit · flip sign
#With digits: reference label · empty: date & time stamp
Hold a lineEdit its amount / note

Decimal modes

Tap the mode button (top-left) to pick: 0dp, 2dp, 3dp, FLT (up to 6 decimals), or ADD — cents-free entry: digits typed without • are hundredths, so 123 ⇒ 1.23 and 1 00 ⇒ 1.00. Type • for exact decimals. % rates are never scaled.

Notes & references

✎ (top bar): Attach prints the text beside the next amount (✎ “Coffee” … 3 + → Coffee  3.00 +); Print label puts text on its own line — leave the field empty to print a dotted divider.

# with digits prints a reference line; empty stamps date & time.

Editing the tape

Hold an amount line (~½ second) to edit its amount or note. Tap-tap still removes a line. Dotted dividers and S/T lines are part of the paper itself — remove them with UNDO, C or double-C. Every removal, edit, merge, replace, transaction clear (C), roll empty (double-C) and roll delete shows an UNDO button in the toast.

Rolls & data

🗂 manages named rolls — switch, create (➕), rename, delete, and 🔍 search: the box matches roll names, notes, # references and amounts across all rolls, showing hit counts and snippets. Each row shows the roll’s last total (or its open running total). ⧉ copies the tape as text; 💾 opens Save / export: Save as JSON (backup/restore), Export CSV (spreadsheets — one row per line, signed amounts, op symbol on every line), or Import (Merge appends / Replace clears first). C starts a new transaction; double-C empties the current roll — saved rolls are never affected.
